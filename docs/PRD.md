# Excel数据处理工具（Excel2Ding）PRD

## 1. 产品概述

### 1.1 产品定位

Excel2Ding 是一款面向企业用户的 **智能化 Excel 数据处理工具**，旨在简化钉钉/企业办公场景下的数据报表处理流程，实现数据读取、清洗、映射、输出的全链路自动化。

### 1.2 目标用户

| 用户角色 | 典型场景 |
|---------|---------|
| 行政/运营人员 | 处理钉钉审批数据，生成统计报表 |
| 项目经理 | 汇总多个项目的定制化需求，分配对接人 |
| 数据分析人员 | 定期清洗和整合业务数据 |

### 1.3 核心价值

- **效率提升**：自动化处理替代手工操作，单次处理时间从 30min 降至 3min
- **零错误率**：标准化映射规则避免人工对照错误
- **灵活配置**：支持自定义列映射和映射规则，适配不同数据源

## 2. 用户问题分析

### 2.1 现状痛点

| 痛点 | 现状描述 | 影响 |
|------|---------|------|
| 多表合并繁琐 | 钉钉导出的 Excel 包含多个工作表，需手动复制粘贴合并 | 耗时且易遗漏 |
| 列名不统一 | 不同月份/部门的 Excel 列名存在差异（如同样的"发起人"可能是"对接人"或"申请人"） | 映射错误 |
| 产品线映射混乱 | 需要根据产品线填写对应"对接人"，手工查找对照表效率低 | 分配错误 |
| 日期筛选困难 | 手工筛选日期范围数据，容易漏选或错选 | 数据不完整 |
| 重复劳动 | 每月/每周需重复处理相同格式的数据 | 资源浪费 |

### 2.2 用户故事

**故事 1：作为运营人员，我希望一次性导入包含多个工作表的 Excel，系统自动合并，避免手动复制粘贴**
- 优先级：P0
- 验收标准：选择文件后，系统自动识别并合并所有有效工作表

**故事 2：作为运营人员，我希望按日期范围筛选数据，只需点击"本周"或"本月"按钮即可完成**
- 优先级：P0
- 验收标准：提供本周/本月/近30天/近90天/自定义日期多种筛选方式

**故事 3：作为项目经理，我希望配置"产品线-对接人"映射表，系统自动填充对接人信息**
- 优先级：P0
- 验收标准：支持添加/删除映射行，支持从文件加载/保存映射配置

**故事 4：作为数据分析人员，我希望自定义列名映射规则，适配不同数据源的列名差异**
- 优先级：P1
- 验收标准：提供可视化界面配置列映射，支持导入/导出配置

**故事 5：作为运营人员，我希望查看映射预览，了解每个产品线匹配到多少条数据**
- 优先级：P2
- 验收标准：点击"映射预览"后弹出统计信息

**故事 6：作为用户，我希望处理进度可见，支持取消操作，避免长时间等待**
- 优先级：P1
- 验收标准：显示进度条，可随时取消处理

### 3.2 功能模块详解

#### 3.2.1 数据处理页签

| 功能 | 描述 | 交互方式 |
|------|------|----------|
| 文件选择 | 选择输入 Excel 文件和输出目录 | 浏览按钮 |
| 日期筛选 | 设置数据筛选的起止日期 | 日期选择器 + 快捷按钮 |
| 快速产品线映射 | 在主页面快速添加单条映射 | 输入框 + 添加按钮 |
| 开始处理 | 执行完整的数据处理流程 | 主按钮 |
| 进度展示 | 显示处理进度百分比和状态 | 进度条弹窗 |
| 结果打开 | 处理完成后打开文件或目录 | 弹窗询问 |

**快捷日期按钮**：
- 本周：自动设置本周一至周日
- 本月：自动设置本月1日至最后一日
- 近30天：自动设置距今30天的范围
- 近90天：自动设置距今90天的范围
- 恢复默认：设置为近一年

#### 3.2.2 产品线映射页签

| 功能 | 描述 |
|------|------|
| 多行映射编辑 | 支持添加/删除多条产品线-对接人映射 |
| 映射计数 | 实时显示当前映射条数 |
| 批量操作 | 新增一行、清空全部、保存到文件、从文件加载 |
| 替换模式 | 覆盖所有 / 仅填空值 |
| 映射预览 | 预览各产品线匹配的数据行数 |

**替换模式说明**：
- **覆盖所有**：无论原对接人是否为空，均替换为映射值
- **仅填空值**：仅对原对接人为空的行进行填充

#### 3.2.3 列映射配置页签

| 功能 | 描述 |
|------|------|
| 列映射配置 | 配置源列名到标准列名的映射关系 |
| 输出列配置 | 配置标准列名到输出列名的映射关系 |
| 导入/导出 | 支持从文件导入配置或导出配置到文件 |
| 保存/刷新 | 保存当前配置或刷新为默认配置 |

### 3.3 数据处理流程

```
1. 文件选择
   └─> 验证文件存在性

2. 工作表识别
   └─> 自动识别包含数据的工作表（至少10行+5列+关键词匹配）

3. 数据读取
   └─> 逐表读取，header=1（第2行作为列名）

4. 列名清洗
   └─> 移除特殊字符，处理 Unnamed: 列

5. 数据合并
   └─> concat 合并所有工作表

6. 日期解析
   └─> 尝试多种格式解析日期字符串

7. 日期筛选
   └─> 按设置的起止日期过滤

8. 列映射匹配
   └─> 根据映射配置匹配源列到目标列

9. 产品线映射
   └─> 按配置替换对接人字段

10. 输出生成
    └─> 按标准列顺序输出，自动调整列宽
```

**输出列顺序**：

## 5. 异常处理

| 场景 | 处理方式 |
|------|----------|
| 文件不存在 | 弹窗提示"输入文件不存在" |
| 无有效工作表 | 弹窗提示"未找到包含数据的工作表" |
| 日期解析失败 | 回退到不过滤，保留所有数据 |
| 映射验证失败 | 弹窗提示具体错误原因，阻断处理 |
| 用户取消 | 关闭进度弹窗，恢复界面状态 |
| 写入失败 | 弹窗提示错误信息 |
